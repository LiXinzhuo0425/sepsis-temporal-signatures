# Version 1.3.1 (2026-08-10)

Version 1.3.1 is a journal-neutral metadata- and wording-only maintenance release. It preserves the corrected v1.2.1 primary numerical workflow, all scientific source values, and the v1.3.0 presentation-facing figures and mappings.

## Changes

- Removed obsolete journal-specific labels from two retained code comments, four internal reproduction-identifier records, five audit labels, and two table-workbook provenance cells.
- Preserved the semantic provenance of the normalized records by retaining their historical version, purpose, audit status, and observed/expected values.
- Clarified the Data S1 and Data S2 README worksheets: v1.3.1 is the current release, the corrected v1.2.1 workflow remains the numerical source, and v1.2.2 remains legacy documentation history.
- Updated release, citation, DOI, changelog, and manifest metadata to version 1.3.1 and DOI `10.5281/zenodo.21862582`.

## Unchanged scientific content

- The frozen v1.2.1 primary analysis was not rerun.
- Cohorts, published formulas, analysis populations, effect estimates, standard and modified Hartung–Knapp results, prediction intervals, heterogeneity estimates, multiplicity conclusions, and gene-contribution metrics.
- All numerical figure-source values and the scientific content of Figures 1–6 and Supplementary Figures S1–S5.
- Frozen v1.2.1 workflow paths and reproducibility snapshots.

The prior v1.3.0 release and all earlier releases remain part of the immutable version history.
